Значения по умолчанию

Подставляется в форму новой проверки. Преподаватель может изменить.
Оценка за оформление всегда считается в процентах; при балльной шкале рядом показывается пересчёт.
Устаревшие проверки удаляются при перезапуске сервера. Отпечатки в базе не трогаются.

Критерии ГОСТ по умолчанию

Сканы и экспорт из LaTeX часто дают ложные срабатывания по шрифту и полям – такие критерии можно снять здесь один раз для всех.

Второе поле – процент использования критерия в рекомендуемой оценке, от 0 до 100. Веса отмеченных критериев приводятся к сумме 100, справа показана итоговая доля. Вес 0 – критерий проверяется и попадает в отзыв студенту, но оценку не меняет. Преподаватель может изменить веса при запуске проверки.

Политика паролей

Пароль всегда должен содержать буквы и цифры.
0 – не требовать периодической смены. Иначе при входе после этого срока система попросит задать новый пароль.
0 – не закрывать вход.

Новая учётная запись и заданный администратором пароль действуют до первого входа: дальше система попросит задать свой. Снять эту галочку для отдельной записи в разделе «Пользователи» нельзя, пока настройка включена.

Доступ по API

Ключ X-API-Key выдаётся конкретной учётной записи в разделе «Пользователи» и работает от её имени: проверки и база остаются в пределах этого преподавателя. Право «Пользоваться API по ключу» должно быть включено.

Выгружаются отпечатки всех преподавателей. Преподаватель выгружает только свою базу – кнопки есть и на странице «База отчётов».

Таблица для Excel (CSV) Полная выгрузка (JSON)

CSV – список работ: студент, группа, файл, версия, дата. JSON – полная копия с отпечатками текста и хешами изображений, годится для переноса базы на другой сервер.
